This is the repository for reproducing the numerical results in the paper "Heteroskedastic Tensor Clustering". 

The following code files run the simulations presented in the paper:

- SNR_balanced.R
- SNR_unbalanced.R
- STBM_unbalanced.R
- clustering_condition_number.R
- constant_choice.R
- heteroskedasticity.R
- iid_sim.R
- larger_size.R

The following code file includes the implementation of our method and baseline methods:
- tensor_clustering_method.R

The following code file includes the real data analysis for the taobao click-through data set:
- taobao.R.
